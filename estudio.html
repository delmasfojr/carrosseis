CONECTAR APARELHO

Aponte a câmera do celular ou do tablet para o código.
Os dois precisam estar no mesmo Wi-Fi.
Abra o link no Chrome (ou Safari), não dentro do leitor de QR.

ou abra:

A câmera não conecta? (servidor de retransmissão)

Quando o roteador não deixa o celular falar direto com o PC (ou o celular está nos dados móveis), o vídeo precisa passar por um servidor de retransmissão. É grátis:

  1. Crie uma conta em metered.ca → TURN Server (plano grátis).
  2. No painel, crie uma credencial e copie o link "API … /turn/credentials?apiKey=…".
  3. Cole aqui, salve e leia o QR code de novo no celular.
